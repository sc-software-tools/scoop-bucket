# SC Utility Suite: Scoop bucket

Free, offline Windows utilities from SC Software, installable with [Scoop](https://scoop.sh).

```powershell
scoop bucket add sc https://github.com/sc-software-tools/scoop-bucket
scoop install sc/heic-studio        # or any app below
```

| App | Install |
|---|---|
| SC Utility Suite (all seven in one app) | `scoop install sc/sc-utility-suite` |
| HEIC Studio: HEIC/AVIF/WebP to JPG, PNG, WebP, PDF | `scoop install sc/heic-studio` |
| PDF Knife: merge, split, extract pages | `scoop install sc/pdf-knife` |
| Archive Unpacker: RAR, 7z, ZIP, TAR | `scoop install sc/archive-unpacker` |
| Media Trim: trim video, extract MP3/WAV | `scoop install sc/media-trim` |
| Dup Scrub: duplicate files and photos | `scoop install sc/dup-scrub` |
| Screen Lens: screen and GIF recorder | `scoop install sc/screen-lens` |
| USB Flasher: bootable USB from ISO/IMG | `scoop install sc/usb-flasher` |

All apps are free to use, with an optional one-time PRO upgrade. Website: https://sc-software-tools.github.io/sc-utility-suite-dist/
